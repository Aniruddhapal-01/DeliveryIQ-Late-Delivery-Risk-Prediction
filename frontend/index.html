Project Overview

DeliveryIQ is an end-to-end machine learning project built around the Olist Brazilian E-Commerce dataset. It analyzes engineered order, payment, product, seller, location and timing features to estimate late-delivery risk.

Interpreting the Results

The validation dataset contains substantially more on-time orders than late orders. This class imbalance makes accuracy alone an unreliable measure of model quality.

The model identifies approximately 36% of late orders in the current validation split. Its precision of around 31% means that some predicted late orders will actually arrive on time.

These results indicate that the model can act as an exploratory risk-screening tool, but it should not be treated as a definitive operational decision-maker.

Metrics are from the development validation split. They are not a guarantee of performance on unseen production data.

How DeliveryIQ Works

An end-to-end workflow connecting data preparation, machine learning and API-based prediction.

  1. Data Preparation

    Multiple Olist datasets containing orders, products, payments, customers and sellers are combined for analysis.

  2. Cleaning & Feature Engineering

    Data quality issues are handled and meaningful features such as approval duration and customer–seller distance are created.

  3. Model Training & Evaluation

    A Random Forest classification pipeline is trained, evaluated and exported for inference.

  4. API-Based Prediction

    The FastAPI backend loads the saved model pipeline, processes submitted features and returns a prediction with its estimated late-delivery probability.

  5. Business Interpretation

    The predicted probability is presented as a risk signal that can help explore prioritization and operational follow-up strategies.
